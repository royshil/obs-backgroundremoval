Building and installing on openSUSE

Tested on openSUSE Tumbleweed.


sudo zypper install --no-recommends cmake ninja git \
  gcc gcc-c++ libcurl-devel qt6-base-devel obs-studio-devel \
  opencv-devel onnxruntime-devel simde-devel
git clone https://github.com/royshil/obs-backgroundremoval.git
cd obs-backgroundremoval
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=RelWithDebInfo \
  -DCMAKE_INSTALL_PREFIX=/usr
cmake --build build --config RelWithDebInfo --parallel
sudo cmake --install build --config RelWithDebInfo --prefix /usr

If you use OBS Studio from a different source (e.g. Flatpak), adjust the install prefix accordingly.
