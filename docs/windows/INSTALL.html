1. INSTALLING THE PLUGIN (royshil/obs-backgroundremoval)

1

Open ProgramData in File Explorer

C:\ProgramData
2

Paste ZIP's 📁 obs-studio into there

Let File Explorer merge it with the existing obs-studio folder. After merging, confirm that this DLL exists:

C:\ProgramData\obs-studio\plugins\obs-backgroundremoval\bin\64bit\obs-backgroundremoval.dll
3

Restart OBS completely

Exit OBS completely and launch it again. The About dialog shown at right confirms the plugin loaded.

2. Common pitfalls when installing OBS plugins

1

Use the latest x64 version of OBS Studio

This plugin is for 64-bit Windows. Make sure you installed the Windows x64 build of OBS Studio.

2

Install OBS Studio on the C drive

By default, OBS Studio is installed on the C drive. The plugin should be installed on the C drive.

3

NEVER put this plugin in C:\Program Files

Do not paste the included obs-studio folder into C:\Program Files. It belongs in C:\ProgramData.

4

C:\ProgramData is the correct location

OBS Studio recommends C:\ProgramData\obs-studio\plugins for Windows plugins. The C:\Program Files location is legacy and will stop working in a future version of OBS Studio. This package already contains the required plugin directory structure, so copy its obs-studio folder into C:\ProgramData and let File Explorer merge the folders.
